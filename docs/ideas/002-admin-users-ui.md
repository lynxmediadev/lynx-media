# 002 · Admin Users UI (filtros/acciones/lista)

## Estado
- `IN_PROGRESS`

## Contexto
La vista de `/admin/users` necesita mejor jerarquía visual en desktop:
- menos altura “muerta” sobre la lista,
- filtros más claros,
- acciones de invitación más ordenadas,
- consistencia visual profesional/minimal.

## Objetivo
Llegar a una versión final con:
- lista visible de inmediato,
- filtros fáciles de entender,
- acciones rápidas sin ensuciar el layout.

## Alcance
- Estructura visual de header/filtros/tabla.
- CTA de invitar (inline o modal).
- Espaciado y alineación de controles.

## Criterio de aceptación
- La lista aparece “above the fold” en desktop.
- No hay campos estirados sin sentido.
- Filtros y acciones se entienden sin explicación extra.
- Diseño consistente con dashboard actual.

## Próximo paso
- Continuar iterando con la dinámica “prueba otra”.
